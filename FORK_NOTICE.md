# Inter Galactic Fork Notice

Inter Galactic is a modified fork of [Commet](https://github.com/commetchat/commet), originally created by [commetchat](https://commet.chat).

Forked: 2026-04-09
Purpose: Discord-style desktop client for a self-hosted Matrix homeserver, with custom branding, extended call layout, sidebar navigation, file-drop UX, and community-specific features built on top of the Commet codebase.
