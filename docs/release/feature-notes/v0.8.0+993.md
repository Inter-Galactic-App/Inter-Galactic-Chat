# Inter Galactic v0.8.0

A hotfix update with reliability fixes for calls, streaming, and the emoticon
creator.

## Calls

- Fixed not being able to rejoin a call shortly after leaving one. Hanging up
  now reliably frees the call, so you can jump right back in without
  restarting the app.
- Joining a call that is already in progress no longer occasionally leaves you
  unable to hear other people. Stalled incoming audio is now detected and
  repaired automatically.
- Smoother, more stable cleanup when leaving or switching between calls.

## Streaming

- Windowed DirectX 11 game streams that started on a black frame now recover on
  their own instead of needing a manual stop and restart.

## Emoticon Creator

- You can now save an emoticon straight from an unedited photo.
- Brought back a dedicated Crop button for trimming a picked image.
- The manual brush now updates live as you paint, instead of only after you
  lift your finger.
- Added a brush opacity slider for softer, more gradual edits.
- On mobile, the on-screen keyboard no longer hides the name field or covers
  the Save and Delete buttons.

## Timeline

- Fixed a duplicate image appearing beneath a grouped photo stack.
