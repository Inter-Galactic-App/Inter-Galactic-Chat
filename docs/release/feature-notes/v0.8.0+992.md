# Inter Galactic v0.8.0

Message effects, themes, and accessibility settings are expanded in this build.

## Call Rooms

- Call room messaging is now easily accessible with new sidepanel chat.
- Individual call panels can now be popped out into their own windows
  with the same transparency ability as the full call popout
- Push to talk has been fully implemented

## Improved Noise Supression

- Noise suppression now uses DeepFilterNet by default. Currently we are also
  testing a transient guard for typing and a background crowd suppressor.

## Emoticon Creator

- An early version of an emoticon creator has been added to remove backgrounds
 from images to create emoticons/stickers.
- This can be found in the main settings -> Emoticons and shows up when you go
 to add an image to a pack

## Message Effects

- Send messages with built-in effects using the composer effect picker:
  `Confetti`, `Rainbow`, `Snowfall`, or `Space invaders`.
- Turn message effects on or off in app settings, and separately control whether
  automatic trigger-based effects are allowed.

## Accessibility

- New accessibility settings now cover contrast, color emphasis, reduced
  motion, text size, link underline style, focus indicators, larger touch
  targets, and pause-animated-media behavior.
- The existing reduced-motion and large-target controls also apply to more chat and
  call-control surfaces for a more comfortable visual flow.

## Themes

- Two new built-in themes were added: **Dark Matter** and **Cosmic Stardust**.
- Dark Matter serves as the new, more modern, dark mode default. The old default,
  **Nebula** is still available.
- Theme selection now includes both new palettes alongside existing options, and
  an improved ui for custom theme creation and editing.

## Other User-Facing Changes

- Stories continue to be improved, make sure you have your notifications on
  for those if you want to see your friends stories.
- Favorites now acts similar to a full personal space, complete with categories.
- Hot keys can be set for rooms in shortcut settings. Call room hotkeys even join
  the call.
