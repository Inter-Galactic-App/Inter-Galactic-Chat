FFmpeg build configuration for the binaries distributed with Inter Galactic
==========================================================================

This file accompanies the Corresponding Source archive and records how the
FFmpeg binaries shipped with Inter Galactic were compiled. It is provided in
the form suggested by https://ffmpeg.org/legal.html ("Explain how you compiled
FFmpeg, for example the configure line, in a text file").

Inter Galactic did NOT modify FFmpeg. The source archive published alongside
this file is upstream FFmpeg at the revision below, unmodified, so there is no
changes.diff to accompany it.

Licence
-------
  LGPL-3.0-or-later. The build sets --enable-version3 and does NOT set
  --enable-gpl; --disable-libx264 and --disable-libx265 are explicit in the
  configure line below. FFmpeg's configure refuses to build if a GPL-only
  EXTERNAL is enabled without --enable-gpl, so the absence of that flag is
  evidence that no GPL-only external library is enabled.

  CORRECTED 2026-08-09. This paragraph used to conclude that the absence of the
  flag was "itself evidence that no GPL-only component is present". That
  inference does not hold and has been disproven against this very binary. The
  configure check covers DIRECT externals and is blind to their dependencies by
  construction. FFTW (GPL-2.0-or-later, fftw-3.3.11) is statically compiled into
  this ffmpeg.exe, reaching it through chromaprint, which BtbN builds with
  -DFFT_LIB=fftw3; chromaprint is LGPL-2.1 and has no entry in
  EXTERNAL_LIBRARY_GPL_LIST, so configure never demanded the flag. libudfread
  (LGPL-2.1-or-later, via libbluray) surfaced the same way. Both are disclosed
  in docs/policies/SOURCE_OFFER.md and docs/policies/THIRD_PARTY_NOTICES.md;
  the owner decision is in workspace docs/DECISIONS.md, "2026-08-09 - Disclose
  FFTW For What Already Shipped; Trim It From Future Builds".

  DIVERGENCE FROM THE SERVED COPY, recorded rather than left silent: this file
  is mirrored publicly as /source/ffmpeg-BUILD-CONFIGURATION.txt, and the served
  copy still carries the uncorrected sentence. Republishing is a RELEASE
  PIPELINE / owner action; until it happens the two differ, and this note is
  where that is written down.
