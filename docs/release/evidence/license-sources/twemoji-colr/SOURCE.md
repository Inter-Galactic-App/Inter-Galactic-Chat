The 12Me21/twemoji-COLR repository describes the project as a Twitter emoji
font in OpenType COLR format. The local `LICENSE.md` preserves the
TwemojiCOLR/Twemoji license evidence used for this release review.

## Release Use

The final notice surface should include TwemojiCOLR/Twemoji attribution,
license links, an indication of changes where applicable, and the Noto Color
Emoji OFL notice if the related Tiamat font ships. Re-audit if either emoji
font is replaced or regenerated.
