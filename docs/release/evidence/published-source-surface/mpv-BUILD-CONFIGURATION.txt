libmpv build configuration for the library distributed with Inter Galactic
=========================================================================

This file accompanies the Corresponding Source archive for `libmpv-2.dll`, the
media playback library bundled with the Windows desktop build. It is provided in
the same form as the FFmpeg one alongside it.

Inter Galactic did NOT modify mpv or FFmpeg. The source archive published with
this file is upstream mpv at the revision below, unmodified, so there is no
changes.diff to accompany it.

Licence
-------
  mpv is LGPL-2.1-or-later in this build. mpv is GPL-2.0-or-later BY DEFAULT and
  LGPL only when built with -Dgpl=false, so the flag below is what determines it.
  The library records its own configuration, and it reads -Dgpl=false.

  This was established from the artefact rather than assumed, and one earlier
  reading of it was wrong: a name-alias table inside the binary lists "direct3d"
  among deprecated video-output aliases, which can be misread as evidence that
  mpv's GPL-only legacy Direct3D output is compiled in. It is not. The output's
  own description string, "Direct3D 9 Renderer", is absent, while sibling
  descriptions such as "Null video output" are present - so the strings survived
  stripping and the absence is real.

FFmpeg inside this library
--------------------------
  FFmpeg is statically compiled into libmpv-2.dll and is a SEPARATE, DIFFERENT
  FFmpeg from the ffmpeg.exe/ffprobe.exe pair also shipped with the desktop
  build. Do not conflate them.

    this one            FFmpeg n6.0, inside libmpv-2.dll
    the executables     FFmpeg n8.1.1-13-g83e8541aa6, see ffmpeg-BUILD-CONFIGURATION.txt

  It is LGPL-3.0-or-later: the configuration below sets --enable-version3 and
  --disable-gpl --disable-nonfree.

The build definition is not recoverable, and that is stated rather than glossed
------------------------------------------------------------------------------
  The scripts that drove this compilation cannot be identified, and no honest
  substitute exists. Searching the full history of both candidate build
  repositories for flags taken from the binary's own configuration line returned
  no commit that could have produced it - "-Dc_link_args=-Wl,--gc-sections"
  appears in no commit of either repository at any point. The release tag that
  would have pinned it points at a branch whose entire tree is a single file
  named "version", and the repository believed to be the builder was archived on
  2024-10-09.

  Publishing a plausible-looking build definition would be worse than publishing
  none, so none is published. What is published instead is the exact upstream
  source, the exact configuration the binary records of itself, and this
  statement.

  If you need to reproduce this library and the above is insufficient, please
  write to intergalactic@ourgalaxy.space and we will help.
