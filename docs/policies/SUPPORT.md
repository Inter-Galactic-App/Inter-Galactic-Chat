# Support

Publication status: public beta support routing. Inbox monitoring is recorded
in `PUBLIC_RELEASE_READINESS_TRACKER.md`; formal response-time commitments
remain deferred until the tracker records them.

Contact email: `intergalactic@ourgalaxy.space`

Use this inbox for support, privacy, abuse, and security routing. Keep any
future routing or response-time changes synchronized with
`PUBLIC_RELEASE_READINESS_TRACKER.md`.

Privacy requests: `intergalactic@ourgalaxy.space`

Abuse reports: use the in-app Matrix report action or selected homeserver's abuse process first. For app-level issues or routing help, contact `intergalactic@ourgalaxy.space`.

Security reports: `intergalactic@ourgalaxy.space`

## What To Include

For support, include your app version, platform, selected homeserver, Matrix user ID if relevant, a clear description, reproduction steps, and screenshots or logs only when they are safe to share.

Bug reports do not support RNNoise WAV/audio diagnostic uploads. RNNoise WAV
captures are local developer diagnostics only; do not manually share local
audio files unless you are comfortable with the recorded sounds they may
contain.

For account deletion, contact the selected homeserver. Inter Galactic can explain the account model, but it cannot delete an account on a homeserver it does not operate.

For abuse, the default path is Matrix-native reporting to the selected homeserver. Inter Galactic can help route app-level problems, but it may not receive or control reports submitted to third-party homeservers.

For security issues, do not post exploit details publicly until the issue has been triaged.

## What Inter Galactic Can Help With

Inter Galactic can help with app bugs, login behavior, Matrix client features, push notification troubleshooting, and E2EE recovery guidance. Homeserver-specific issues belong to the selected homeserver operator.

Inter Galactic may not be able to help with homeserver outages, Matrix.org account decisions, self-hosted server policy, remote room moderation, or third-party service outages.

## Response Expectations

Inter Galactic has not published formal response-time commitments yet. Track
support, privacy, abuse, and security queue expectations in
`PUBLIC_RELEASE_READINESS_TRACKER.md`.
