# Demo imagery credits

These images are used only by the offline demo account (`DemoClient`) to
replace placeholder icons for account avatars, the demo space icon/heading,
room icons, and the memory-vault photos.

Source: NASA Goddard Space Flight Center image archive (GSFC_20171208_Archive_*).
NASA imagery is generally not copyrighted and is free to use; see
<https://www.nasa.gov/nasa-brand-center/images-and-media/>.

Files were renamed from their original `GSFC_20171208_Archive_e######~*` names
to semantic demo names (`avatar-*`, `space-*`, `room-*`, `vault-*`, `story-*`).
Original
archive ids are recorded in the branch history if the source needs to be traced.
