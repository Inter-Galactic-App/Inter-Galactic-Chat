DEEPFILTERNET libDF RUST COMPONENTS LINKED INTO THE APPLICATION
===============================================================================

The DeepFilterNet native C API runtime used by this application is
implemented in Rust. Windows distributes it as df.dll; Android
distributes it as libdf.so for arm64-v8a and armeabi-v7a. These are
native payloads, so automatic package-notice surfaces do not enumerate
the Rust crates compiled into them. This document is the notice that
travels with those native payloads and is rendered on the app's open
source licences screen.

The selected dependency closures contain 95 Windows packages, 105
Android packages, and 109 unique package/version pairs. Each row names
the exact captured version, its declared licence expression, delivered
platform scope, and every captured licence text. Identical text is
printed once and referenced by block identifier. This deduplicates bytes
only: it does not elect a licence arm for a multi-licensed package.

The Rust standard library is also linked into these binaries. It was
built with rustc 1.94.1, commit e408947bfd200af42db322daf0fadfe7e26d3bd1, and its
Apache-2.0 and MIT texts are included below.
