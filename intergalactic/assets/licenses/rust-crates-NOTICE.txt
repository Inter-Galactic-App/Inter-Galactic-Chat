RUST COMPONENTS LINKED INTO THE APPLICATION BINARY
===============================================================================

The Matrix end-to-end encryption in this app is provided by vodozemac,
which is written in Rust. It is not loaded as a separate library the way
the media components are. The Rust code is compiled to a static archive
and merged into the application executable at link time, so on Apple
platforms it has no file of its own inside the app bundle, and on Android
and Windows it arrives inside libvodozemac_bindings_dart.so / .dll.

Because of that, none of the automatic licence surfaces can see these
components: they list packages, and this is not shipped as a package.
This file is the notice that travels with them instead. It is rendered on
the app's own open source licences screen.

Each component below is listed with the exact version that was compiled
in, the licence its authors declared, and the full text of every licence
file that component ships. Where two components ship the identical text,
the text appears once and both components point at it. That is a saving
of duplicated bytes only - where a component offers a choice of licences,
every one of its texts is reproduced here, and no choice has been made on
your behalf.

The component versions were read out of a compiled binary rather than
from a build file, so this list describes what actually shipped. The
binary read was the iOS one. Android and Windows compile the same pinned
crate list from the same lockfile inside the same package, so the
components and their versions are the same there; what can differ between
platforms is the Rust toolchain named below, and with it the versions of
the standard library's own bundled dependencies.
